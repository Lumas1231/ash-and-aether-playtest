# Ash and Aether playtest

[Download the Windows game](https://github.com/Lumas1231/ash-and-aether-playtest/releases/latest)

1. Download the ZIP from the latest release and extract it.
2. Double-click **Play.cmd**, enter a name and pick a class.
3. You join the shared testing ground. Nothing else to install or configure.

The world runs on Jackson's PC and is online while he is hosting. If Play says the world is offline, try again later. Run Play again after a disconnection; it always finds the current host address.

This repository holds only the playtest downloads and `server.json`, the address of the current host, which Play.cmd reads. The build is unsigned and experimental.
